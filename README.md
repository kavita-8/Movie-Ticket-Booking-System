# Movie-Ticket-Booking-System
The Movie Ticket Booking System is a console-based application developed in C++ to simulate the basic operations of a cinema ticket booking platform. The system allows users to view available movies, show timings, screens, and seat availability before making a booking.

Users can select a movie show, choose one or more seats, and book tickets according to different seat categories: Silver (₹150), Gold (₹250), and Platinum (₹400). The system supports multiple payment methods, including UPI, Card, and Cash. A booking is confirmed only after successful payment, and a ticket containing the booking details is generated.

The system also provides functionality to view bookings, print tickets, cancel bookings, and automatically release seats when a booking is cancelled. Failed payments do not result in confirmed bookings, ensuring that seats remain available.

The project follows an Object-Oriented Programming and System Design approach. It is structured into multiple classes such as Movie, Cinema, Screen, Seat, Show, Customer, Booking, Payment, and BookingService.

The design demonstrates important software engineering concepts including encapsulation, inheritance, polymorphism, abstraction, composition, aggregation, association, and SOLID principles. UML Class and Sequence Diagrams are used to represent the structure and behavior of the system.

Overall, the project provides a simple and practical implementation of a movie ticket booking workflow while demonstrating how object-oriented concepts can be applied to design a modular and maintainable software system.
